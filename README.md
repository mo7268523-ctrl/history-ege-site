# История — публичные карточки ЕГЭ

Рабочая версия V240. Приложение, данные карточек и изображения находятся в `site/`.

GitHub Pages публикует файлы из `site/` после изменений в ветке `main`. Первичный перенос сверяется по SHA-256 с `publication.json`; после переноса сайт обслуживается GitHub независимо от прежнего хостинга.

Локальный запуск: `python -m http.server 8000 --directory site`.

Опись фиксирует исходный выпуск и его контрольные суммы. Для нового выпуска обновите опись и запустите публикацию с параметром `import_release`, либо внесите проверенные изменения непосредственно в `site/`.
