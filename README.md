## Рабочая версия

Код приложения, данные карточек и изображения находятся в [site/](site/). Изменения этого каталога в ветке `main` автоматически публикуются через GitHub Actions. Сайт обслуживается GitHub Pages независимо от прежнего хостинга.

Локальный запуск: `python -m http.server 8000 --directory site`.

## Проверка переноса

799 файлов V240 сверены по SHA-256 с описью `publication.json`. [Успешная публикация](https://github.com/mo7268523-ctrl/history-ege-site/actions/runs/43979949854). Коммит сохранённых файлов: `de7ce1dd8a8a87b3d8b81b7ad488d8fbaf05127c`.

В браузере проверены три темы, переход к заданию 725400, открытие оригинального снимка и возврат к материалу. Полная смысловая готовность всех учебных материалов и приёмка на физическом iPad этим переносом не подтверждаются.

Файлы `site-small-*.zip` — сверенные части первичной загрузки; `tools/import_public_release.py` восстанавливает из них исходный выпуск. Для дальнейшей работы изменяйте файлы `site/`; подготовка и перенос нового выпуска из закрытого проекта являются отдельным этапом. После изменения состава файлов обновляйте опись, проверяйте сборку и открытие опубликованного сайта.
